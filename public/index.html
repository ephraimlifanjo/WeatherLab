Inside the NoSQL Lab ✳

Two database engines. One beautifully simple weather app.

M

MongoDB

Document database

Checking...

Stores saved cities as flexible JSON-like documents, grouped by anonymous browser ID.

// Example city document
{
  "name": "Douala",
  "country": "Cameroon",
  "lat": 4.0511,
  "lon": 9.7679
}
Collection: favorites
C

Apache Cassandra

Wide-column database

Checking...

Stores time-series weather observations, partitioned by city and observation day.

-- CQL, Cassandra Query Language
SELECT temperature,
  observed_at
FROM weather_by_city_day
WHERE city_key = ?
AND observed_day = ?;
Table: weather_by_city_day

Weather observation history

Actual observations written by Cassandra when you load a city. No fabricated entries.
